LIBRERIA DON BOSCO HUANCAYO
======================================================================

DESCRIPCIÓN:
Este proyecto es una plataforma web de comercio electrónico para la 
Librería Don Bosco en Huancayo, que permite a los usuarios explorar 
el catálogo de libros, gestionar un carrito y realizar compras en línea.

ACCESO A LA APLICACIÓN:
Para ingresar a la plataforma web de cara al usuario, utiliza:
https://alwaysdata.net

----------------------------------------------------------------------
GUÍA DE USO PARA EL USUARIO
----------------------------------------------------------------------

1. EXPLORAR EL CATÁLOGO:
   - Ingresa al enlace de la aplicación.
   - Navega por las secciones y escoge tus productos.

2. GESTIONAR EL CARRITO:
   - Agrega los productos seleccionados al carrito de compras.
   - Accede al carrito para revisar tu pedido.

3. INICIAR SESIÓN O REGISTRARSE:
   - Para continuar con la compra, debes identificarte.
   - Puedes usar esta cuenta de prueba:
     * Correo: cliente@mail.com
     * Contraseña: 123456
   - O si lo prefieres, regístrate creando una cuenta con cualquier 
     correo electrónico válido.

4. PROCESO DE COMPRA:
   - Una vez iniciada la sesión, regresa al carrito de compras.
   - Selecciona el tipo de entrega: "Delivery" o "Recojo en tienda".
   - Introduce tus datos de facturación:
     * DNI (para Boleta de venta).
     * RUC (para Factura comercial).

5. PAGO Y CONFIRMACIÓN:
   - Continúa hacia la sección de pago.
   - Escoge tu método de pago preferido y finaliza la transacción.

6. SEGUIMIENTO:
   - Dirígete a la sección "Pedidos" en tu perfil para verificar 
     el estado actual de tu compra.
